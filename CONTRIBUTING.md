# Contributing

## How to contribute

- Open an issue to discuss a bug or an idea before larger changes. Security problems go privately through [SECURITY.md](SECURITY.md), never in a public issue.
- Send a pull request: one topic per PR. Run `make check` before pushing. Build, test and CI details: [docs/development.md](docs/development.md).
- Language: everything is English (code, comments, UI, docs, commit messages, PRs).

## Hard rules

- No ROMs, BIOS, firmware or keys in the repository or in tests. Use homebrew ROMs or dummy files only.
- No circumvention tooling, and no dumping guides that rely on circumvention tools.
- No piracy wording in code, docs, issues or PRs.
- Never overwrite saves silently, never send them to another server, never put secrets in files, profiles or logs.

## Contributor License Agreement

Contributions require agreeing to the [CLA](CLA.md). It lets the project owner relicense contributions, including under other or commercial terms (dual licensing); the published versions stay available under GPL-3.0-or-later. You keep your copyright.

To agree, tick the CLA box in the pull request template. Writing "I have read the CLA and agree to it" as the first comment on your first PR is also accepted. There is no bot; maintainers check manually.
