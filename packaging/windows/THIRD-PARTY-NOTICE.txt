This package contains no emulator cores. Emulator cores (e.g. melonDS DS, GPL-3.0) are
downloaded from your Uzume server when needed; the server provides each core together with its
licence text and source link.
Contains no ROMs, BIOS or firmware.

Further bundled libraries (built via vcpkg, see client/vcpkg.json):
- FFmpeg (avcodec, avutil, swscale), LGPL-2.1-or-later, https://ffmpeg.org/ (source: https://git.ffmpeg.org/ffmpeg.git);
  hardware encoder support uses nv-codec-headers (MIT), libvpl (MIT) and AMF headers (MIT)
- OpenH264, BSD-2-Clause, https://github.com/cisco/openh264
- libdatachannel, MPL-2.0, https://github.com/paullouisageneau/libdatachannel (uses plog, MIT)
- libjuice, MPL-2.0, https://github.com/paullouisageneau/libjuice
- libsrtp, BSD-3-Clause, https://github.com/cisco/libsrtp
- Lua 5.4.7 (plugin runtime), MIT, Copyright (C) 1994-2024 Lua.org, PUC-Rio, https://www.lua.org/ (source: https://www.lua.org/ftp/)
- zlib puff.c (altered, inflate for .uzplugin files), zlib license, Copyright (C) 2002-2013 Mark Adler, https://zlib.net/ (source: client/plugins/uzplugin.cpp)
- usrsctp, BSD-3-Clause, https://github.com/sctplab/usrsctp
- Opus, BSD-3-Clause, https://opus-codec.org/ (source: https://gitlab.xiph.org/xiph/opus)

The FFmpeg and Qt DLLs are shared libraries and can be replaced by compatible builds.
