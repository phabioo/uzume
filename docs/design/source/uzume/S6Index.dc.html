Decisions that change earlier boards
  1. Yellow is for acting. Primary button, focus ring, active nav and tab marker. Selected chips, segments and rows are neutral: an ink plane, or the selected tint with a 2 px ink marker. All boards.
  2. Warnings are a sentence. Ink text with the small Yamabuki square, no separate warning hue, never colour alone. All boards.
  3. Status filters with counts are always visible in the library toolbar, next to collections, search and sort. 3c-1, 3c-2.
  4. List and grid. The grid comes back with monogram tiles, a system chip and a status line; the list shows the system as a chip. 3c-2.
  5. One problem, once. The game detail shows a problem as one sentence with its fix. When the game cannot start, the fix becomes the primary ("Install core and play"). The start checklist only appears while starting or after a failure. 3c-1.
  6. Saves: start actions stay on top; SHA-256 and the local path sit under a closed "File details". 3c-3.
  7. Game header: Pause / Resume is the primary, Fullscreen is back as an icon button with a tooltip, Diagnostics and the rest stay in ⋯. 3g-1.
  8. Plugin tabs show icon and label; overflow goes into "More". 3g-1.
  9. Diagnostics get a visible "Details" section; the hold-Select sheet gets Diagnostics. 3g-6.
  10. Three columns at 1280. The input test moves into a disclosure under the device header; help columns become a "Help" disclosure. 9a-1, 6f, 3n.
  11. Mapping table shows the key once; "Default" and Reset only on changed rows. 9a-1.
  12. Appearance gains Text size (100 % · 125 % · TV) and Reduce motion. 9c-1.
  13. Nav badges for Systems & cores (core problems) and Settings (server update), besides Status. 6f.
  14. Wide fonts: page header actions wrap below the title; dialog buttons stack inside the dialog. 6f, 0-r6-pad-2.
  15. HintRow on every main page while the last input was a gamepad. 0-r6-pad-1, 0-r6-pad-2.
